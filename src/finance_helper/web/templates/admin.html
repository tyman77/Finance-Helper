1. Historical United export

Upload the same "United Flights" historical categorization CSV used locally. Builds both the traveler map and the client→project registry from it.

2. Roster (traveler → calendar)

Auto-drafted from the traveler map, via the work-email convention plus known vanity calendars. Requires step 1 first.

3. Crew schedule (installers)

Reads the crew-schedule Google Sheet live. Requires SCHEDULE_SHEET_ID and Google credentials configured as environment variables.

4. Traveler calendars

Reads each traveler's own Google Calendar for trip context. Requires step 2 (roster) first, and Google credentials configured. Can take a few minutes for a large roster or wide date range — let it run.

5. Sage projects (active/archived)

Pulls the Projects list from Sage Intacct using the same credentials already configured for posting journal entries.

6. Hotel Engine cross-reference (better project matches)

Upload a Hotel Engine statement CSV. It builds a date→project index (no traveler names needed) so United flights can be matched to the project that had a hotel booked the same week — narrowing the "pick one" project chips, often to a single confident match. Upload each month's statement as it comes in; they accumulate.

7. Chart of accounts

Upload a Sage Intacct General Ledger account export CSV to capture posting rules (which accounts require a department, which are disallowed for direct posting).
